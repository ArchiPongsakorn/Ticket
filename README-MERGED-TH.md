# Nextpro + AdminUI (ตรวจแก้แล้ว)

โปรเจกต์นี้ใช้ **nextpro เป็น Base หลัก** และนำโค้ด AdminUI มาเป็น `/admin`.

โปรดอ่าน `README-CHECK-TH.md` สำหรับวิธีรัน สถานะการตรวจสอบ และข้อจำกัดที่สำคัญ.

```bash
npm install
npm run verify
npm run typecheck
npm run build
npm run dev
```

ตั้งค่า `.env.local` จาก `.env.example` ก่อนเปิดใช้ `/admin` บน Production.
